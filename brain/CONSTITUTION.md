# JUNGLE CONSTITUTION

1. Do not directly modify Production without validation.
2. Test meaningful changes in Sandbox first.
3. Do not automatically install newly discovered Skills, MCPs, repositories, or tools.
4. New components must be evaluated before adoption.
5. Existing functionality must pass regression testing after important changes.
6. Maintain a rollback path for Production changes.
7. Record important decisions, failures, fixes, and reusable learnings.
8. Prefer verified evidence over agent assumptions.
9. Separate the roles of Claude, Codex, GPT, tools, and specialist agents when useful.
10. Do not let an agent exceed user-approved authority.
11. Secrets, tokens, passwords, and credentials must not be committed to Git.
12. Jungle knowledge must remain portable across AI accounts and models.
